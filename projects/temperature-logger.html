Temperature Logger

A console program that takes temperature readings in a loop, validates each one, and reports the average, highest, lowest and how many fell below a safe minimum.

PythonPyCharmAS Computer Science

Demo

How it works

The program keeps asking for a temperature inside a while loop until the user types -1. Each reading is checked against a valid range of 10 to 50; anything outside prints a message and is ignored. Valid readings are counted and added to a running total, compared against the current highest and lowest, and compared against MIN_SAFE_TEMP (a constant set to 18) so the program can count how many readings fell below the safe minimum.

Typing a word instead of a number would normally crash the program, so the input sits inside a try / except block: a ValueError is caught and the user is told the temperature must be an integer. Once the loop ends, the average is calculated from valid readings only and the results are printed with f-strings.

Written as part of Archie’s AS Level Computer Science course, this covers the fundamentals that carry straight into game scripting: loops, conditionals, constants, exception handling and running totals.

Featured code

Kept exactly as written, spelling included. The structure is the point: one loop, one guard against bad input, every rule its own if.
