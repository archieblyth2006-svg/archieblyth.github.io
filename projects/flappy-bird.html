C# in Unity

Flappy Bird

C# game logic in Unity: a timer-driven procedural spawner, frame-rate-independent movement, trigger-collider scoring and state handling, plus a second controller for two-player mode.

C#Unity 62D

Demo

How it works

A GameManager spawns pipe prefabs on a timer at a random height, pipes scroll left with frame-rate-independent movement, and trigger colliders handle scoring, cleanup and collisions. The bird applies constant drop speed with an instant jump on input, and freezes time on game over. A second bird script adds two-player racing on a separate input.

Featured code

Pipes spawn at a random Y each cycle so every run is different; Time.deltaTime keeps the countdown consistent at any frame rate. Scoring uses trigger colliders between pipe pairs: each gate adds 0.5, floored for display, and hitting the target score activates the finish line.
